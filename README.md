# Virtual Event Platform

This is a simple MERN-based Virtual Event Platform demonstrating:
- Payment & Ticketing Integration (placeholder)
- Live Video Streaming (WebRTC placeholder)
- Email & Push Notifications (stub implementations)
- Advanced Analytics Dashboard (basic structure)
- Separate Dashboards for Organizers & Attendees

## Quick Start

1. At the root, run:
   npm install
2. In the backend folder:
   cd backend && npm install
3. In the client folder:
   cd ../client && npm install
4. Run the project:
   cd .. && npm run dev

Front end will be accessible at http://localhost:3000  
Back end at http://localhost:5000

## Note
This project is for learning purposes. It is not production-ready.
